# Architecture Decision Records

Durable design decisions worth explaining to a future reader. Small/routine decisions can
stay in `docs/architecture.md` §Architectural Decisions; use an ADR here when a choice has
real trade-offs, was contentious, or would otherwise be re-litigated later.

One file per decision: `NNNN-short-slug.md`, with sections **Context**, **Decision**,
**Consequences**, and a status (Proposed / Accepted / Superseded).
